# Survivors of Victory 3D — Downloads

An unofficial, non-commercial fan game based on *Goddess of Victory: NIKKE*. Not affiliated with,
endorsed by, or sponsored by SHIFT UP or any official partners. All trademarks and characters
belong to their respective owners.

## Download

Get the latest Windows installer from **[Releases](../../releases/latest)**
(`SurvivorsOfVictory-Setup-<version>.exe`). Installed copies update themselves automatically.

The browser version is on itch.io.

This repository only hosts release builds; it contains no source code.
